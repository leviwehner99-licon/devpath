INSTALLATION

In drei Schritten startklar

  1. Installer ladenWähle oben „Windows-Installer herunterladen“.
  2. Datei öffnenÖffne die heruntergeladene Datei und bestätige den Windows-Hinweis nur, wenn du die Alpha bewusst ausprobieren möchtest.
  3. DevPath startenNach der Installation findest du DevPath im Startmenü und auf dem Desktop.
Hinweis zur Alpha

Diese unsignierte Vorabversion dient zum Ausprobieren. Windows kann deshalb eine Warnung zu einem unbekannten Herausgeber anzeigen. Sie ist keine Aussage darüber, dass die Datei bösartig ist oder sicher geprüft wurde. Installiere sie nur, wenn du diesem Projekt vertraust. macOS- und Linux-Installer sind noch nicht veröffentlicht.
