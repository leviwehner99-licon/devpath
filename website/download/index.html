INSTALLATION

In wenigen Schritten startklar

  1. 1. Passendes Paket ladenWähle oben das Paket für dein Betriebssystem und lade es herunter.
  2. 2. Installer öffnenDiese Alpha ist nicht digital signiert. Betriebssysteme können deshalb eine Herausgeber-Warnung anzeigen. Installiere sie nur, wenn du devpath vertraust.
  3. 3. Lernplan einrichtenBeim ersten App-Start beantwortest du einmalig die Startabfrage für dein lokales Profil. Erst nach erfolgreichem Speichern öffnet sich dein Lernraum.
Alpha- und Installationsinfo

Windows-Installer, macOS-DMGs und das Linux-Paket werden derzeit ohne Codesignatur gebaut. Das Betriebssystem kann beim Öffnen deshalb eine Herausgeber-Warnung anzeigen. macOS kann eine unsignierte App zunächst blockieren. Das Linux-Paket ist für Ubuntu/Debian x64 vorgesehen. Die Downloads werden nach erfolgreichem Plattformbuild freigeschaltet.
