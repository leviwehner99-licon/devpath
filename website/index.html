LOKAL ZUERST

Dein Code ist deiner.

DevPath ist als Desktop-App geplant. Code Studio und Code Base sollen überwiegend direkt auf deinem Rechner laufen. Wenn eine Funktion Daten online verarbeitet, soll DevPath dir zeigen, was übertragen wird und wohin.

  • Projekte bleiben standardmäßig lokal
  • KI-Hilfe mit sichtbarem Umfang und deiner Kontrolle
  • Community-Veröffentlichungen nur, wenn du sie startest
