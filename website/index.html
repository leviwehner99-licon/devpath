DEIN START IN DREI SCHRITTEN

Vom ersten Ziel zum ersten Programm.

Du brauchst keine Vorkenntnisse. devpath führt dich vom ersten Befehl bis zu einem kleinen eigenen Projekt.

01

Richte deinen Lernplan ein

Beim ersten Öffnen fragt devpath nach deinem Namen, deinem Lernziel, deiner Erfahrung und deinem gewünschten Wochenrhythmus. Die Abfrage wird für dein lokales Profil gespeichert.

02

Übe mit sieben Lektionen

Der verfügbare Einstiegskurs erklärt Ausgaben, Variablen, Datentypen, Bedingungen, Schleifen und Funktionen – mit kleinen Aufgaben direkt im Editor.

03

Baue eigene Projekte

Öffne Code Studio, verwalte deine Dateien und sichere Zwischenstände in Code Base. Der lokale Tutor gibt Hinweise, ohne deinen Code ungefragt umzuschreiben.

LOKAL ZUERST

Deine Projekte gehören dir.

Die aktuelle Desktop-Alpha speichert dein lokales Profil, den Lernfortschritt und deine Projekte auf deinem Gerät. Du brauchst für diese Offline-Funktionen kein Konto.

  • Die Startabfrage wird einmal pro lokalem Profil angezeigt und erst nach erfolgreichem Speichern geschlossen.
  • Die Desktop-App sendet weder Projektcode noch Lernaktivitäten an ein KI-Modell.
  • Website und öffentliche Kurs-API sind getrennte Dienste; die API liefert veröffentlichte Kursinformationen, keine lokalen App-Daten.
  • Community-Upload, Cloud-Synchronisierung und externe KI sind noch nicht aktiv.

Die Präsentationsseite beschreibt den tatsächlich verfügbaren Kurs und kennzeichnet weitere Inhalte als geplant. Hosting kann technische Verbindungsdaten verarbeiten; dies ist keine vollständige Datenschutzerklärung.
